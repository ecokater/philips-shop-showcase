# 架构概念说明（无源码）

本文档只讲“这个系统由哪些部分组成、数据怎么流转”，不含任何可运行源码。

## 角色与终端

| 角色 | 使用终端 | 主要事项 |
|---|---|---|
| 消费者 | 微信小程序 / H5 | 浏览、对比、加购、下单、查订单、申请退款 |
| 销售 / 店员 | Web 后台、Android App | 代客下单、接单、发货、收款登记 |
| 仓库 | Android App（扫码）、Web 后台 | 扫码出入库、出库留证拍照、库存修正 |
| 财务 | Web 后台 | 记一笔、转账、流水对账、往来结算 |
| 老板 | Web 后台 | 经营概况、报表、业绩、审计日志 |

## 数据链路

```
消费者下单 → 订单(待支付) → 支付登记(已支付) → 扫码绑定单品 → 发货(已发货)
  → 确认收货(已完成) ／ 取消(回补库存) ／ 退款(退款中 → 已退款)
```

- 库存与资金变动在同一事务内完成，失败整体回滚。
- 每个关键动作写审计日志：谁、何时、对什么单据、做了什么。
- 出库可附现场照片（≤9 张），订单与出入库记录均可回看。

## 部署形态（概念）

- 反向代理统一 HTTPS 入口：管理后台静态页、API、健康检查。
- 应用与数据库跑在容器里，一键起停；每日备份数据库与上传文件。
- Android App 跟随 Web 版本自更新：版本检查接口 + APK 下载。
