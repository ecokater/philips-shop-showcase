# 常见问题 FAQ

## 这是开源项目吗？可以拿到源码吗？

本仓库是**项目介绍页**，只含截图与文档，**不含源码、不提供下载和部署教程**。
合作或学习交流请联系作者。

## 线上地址能直接登录体验吗？

线上为真实经营环境，不开放注册和试用账号。如需看演示请联系作者约演示。

## 支持微信支付吗？

当前为线下收款模式（后台“确认收款”登记）。微信支付 V3 的通道逻辑已预留，待商户号、APIv3 密钥与证书就绪后接入。

## 小程序能直接搜到吗？

小程序为体验版，按需开放体验码，不在公开市场直接上架。

## 能给我们店也做一套吗？

欢迎联系作者聊需求：单店版、连锁版、一物一码、扫码枪/盘点机对接均可按需评估。
